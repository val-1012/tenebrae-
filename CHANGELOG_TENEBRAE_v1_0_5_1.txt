TENEBRAE v1.0.5.1 — 변경 내역

1. 일시정지 상세 화면
- 기존 pausePanel 고정 크기(760×490) 때문에 상세 정보가 좁게 표시되던 문제를 수정.
- pauseMenu 내부 패널을 1280×720 게임 화면 전체 크기로 확장.
- 딜량/도감/아티팩트 상세 페이지가 배틀 화면 전체를 덮도록 변경.
- 페이지 제목과 일시정지 메뉴 복귀 버튼을 유지.
- 모바일 가로 화면에서 카드/도감 그리드와 텍스트 크기를 별도 조정.

2. 포기하고 나가기
- 브라우저 기본 confirm() 의존 제거.
- 게임 내부 확인 다이얼로그 추가.
- 포기 확정 시 현재 전투를 즉시 정리하고 허브로 복귀.
- 스테이지 번호와 영구 코인/영웅 진행도는 유지.
- 이번 전투 임시 코인과 스테이지 한정 강화는 지급/보존하지 않음.
- 전투 결과창을 띄우지 않으며, 이어하기 체크포인트를 삭제.

3. 저장 안정성
- 저장 완료 상태 표시 및 '지금 저장' 버튼 추가.
- localStorage 저장 직후 재읽기 검증.
- IndexedDB 저장을 순차 처리하고 기록 후 재읽기 검증.
- 저장 실패 여부를 성공으로 잘못 반환하던 처리 개선.
- 5초 간격 계정 자동 저장 및 전투 체크포인트 저장.
- 저장 복구 차단 상태에서는 기존 저장을 덮어쓰지 않는 원칙 유지.

4. 변경하지 않은 항목
- 영웅 카드 108장, 진화, 궁극기 설계 및 밸런스.
- 영웅/몬스터/보스 아트워크.
- 소환수 밸런스.
- 웨이브 길이, 몬스터 수치 및 기본 전투 규칙.

5. 검증 범위 및 한계
- Node.js JavaScript 문법 검사 통과.
- 현재 실행 환경의 Chromium이 로컬/테스트 서버 탐색을 보안 정책으로 차단하여 실제 UI 런타임 테스트를 끝까지 진행하지 못함.
- 파일을 실제 사용하는 브라우저에서 상세 화면 전환, 포기 처리, 닫았다 다시 열기 저장 테스트가 필요함.
- file:// 저장소는 브라우저 및 파일 경로에 따라 분리될 수 있으므로, 버전 간 데이터 이동은 JSON 저장 백업/복원을 사용해야 함.
