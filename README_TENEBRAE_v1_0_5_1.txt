TENEBRAE v1.0.5.1 — 일시정지·포기·저장 안정화 핫픽스

[실행]
1. TENEBRAE_v1_0_5_1.html 파일을 다운로드합니다.
2. 가능하면 이전과 동일한 브라우저와 동일한 파일 경로에서 엽니다.
3. PC는 Chrome 또는 Edge, 휴대폰은 HTML 파일 열기를 지원하는 브라우저에서 가로 화면으로 실행합니다.

[이번 핫픽스]
- 일시정지 하위 페이지를 760×490 안의 작은 패널 대신 게임 화면 전체를 덮는 독립 뷰로 표시합니다.
- 영웅 딜량, 몬스터·보스 도감, 현재 아티팩트, 전체 아티팩트 화면에서 전체 화면 공간을 사용합니다.
- 상세 페이지에서는 상단 제목과 하단 '일시정지 메뉴' 복귀 버튼을 제공합니다.
- '포기하고 나가기'는 브라우저 기본 confirm()에 의존하지 않고 게임 내부 확인창을 사용합니다.
- 포기 확정 시 임시 보상은 지급하지 않고, 현재 스테이지를 진행한 상태로 허브에 복귀합니다.
- 결과 화면의 '성 함락'을 거치지 않고 전투 상태, 결과창, 카드창 및 이어하기 체크포인트를 정리합니다.
- 저장 완료 여부를 허브 상단에 표시하고 '지금 저장' 버튼을 추가합니다.
- 계정 저장 시 localStorage 기록을 즉시 쓰고 다시 읽어 검증합니다.
- IndexedDB에도 순차적으로 저장한 뒤 읽기 검증을 수행합니다.
- 5초 주기로 계정과 진행 중 전투 체크포인트를 자동 저장합니다.
- IndexedDB 저장 완료 전에 성공으로 표시하던 기존 낙관적 처리 방식을 수정했습니다.

[저장 관련 중요 안내]
- 브라우저 저장 데이터는 브라우저·기기·사이트/파일 출처별로 분리될 수 있습니다.
- HTML 파일을 다른 폴더로 옮기거나 이름을 바꾸거나 새 버전 파일로 교체하면 file:// 저장소가 달라질 수 있습니다.
- 기존 데이터를 새 파일로 옮길 때는 이전 버전에서 '저장 백업'을 눌러 JSON을 내보낸 뒤 새 버전에서 '백업 불러오기'를 사용하세요.
- 저장 상태가 '저장 실패'로 표시되면 브라우저 저장 공간이 막혔거나 쓰기 검증에 실패한 것입니다. 이때 진행 상황을 보존하려면 '저장 백업' JSON을 별도로 내려받아야 합니다.
- PC와 휴대폰의 저장 데이터는 자동 동기화되지 않습니다. 기기 간 이전은 JSON 백업/복원으로 합니다.

[테스트 범위]
- JavaScript 문법 검사 수행.
- 실제 브라우저 네비게이션 테스트는 실행 환경의 브라우저 보안 정책으로 차단되어 완료하지 못했습니다.
- 따라서 사용자 PC/휴대폰에서의 실제 저장 지속성 및 전체 플레이 테스트는 별도로 확인해야 합니다.
